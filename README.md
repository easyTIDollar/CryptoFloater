# CryptoFloater 📈

一个专为加密货币交易者设计的 Android 辅助工具。它提供了一个全局悬浮窗，可以让你在刷网页、看视频或使用其他应用时，实时监控你关注的币种价格，并内置了便捷的滚仓收益计算器。

## ✨ 核心功能

* **实时全局悬浮窗**：在屏幕任意位置悬浮显示实时币价，支持拖拽和屏幕边缘自动贴合折叠。
* **毫秒级 WebSocket 刷新**：底层采用 OkHttp WebSocket 保持长连接，数据延迟极低。
* **后台防杀保活**：基于 Android 原生前台服务（Foreground Service）与网络心跳机制，确保应用退到后台后依然能稳定获取行情。
* **多币种自定义**：支持动态添加、修改和删除你关注的币种及其对应赔率。
* **滚仓收益计算器**：内置复利计算模型，快速推算不同本金、不同期数下的预估收益。
* **沉浸式 UI 体验**：主界面采用现代化 Jetpack Compose 构建，全面支持深色/浅色模式以及 Android 12+ 的 Material You 动态取色。

## 🛠 技术栈

* **语言**：Kotlin
* **UI 框架**：Jetpack Compose (主界面) + 原生 WindowManager (悬浮窗)
* **网络通信**：OkHttp3 (WebSocket)
* **异步处理**：Kotlin Coroutines (协程)
* **本地存储**：SharedPreferences + Gson
